# Telegram-бот "ЖК Волна" (Уфа)

Этот репозиторий содержит готовый шаблон чат-бота для Telegram, который:

- автоматически отвечает на вопросы потенциальных клиентов с помощью LLM (например, OpenAI или любой совместимой API);
- сам задаёт уточняющие вопросы, чтобы собрать контакты и потребности;
- сохраняет все переписки в базе SQLite, чтобы вы могли просматривать их позже;
- позволяет в любой момент подключиться вручную и ответить пользователю через операторскую консоль.

Ниже — полный план запуска бота «для чайников» и советы по настройке.

## Что понадобится

1. **Телефон с Telegram** — чтобы создать бота через @BotFather.
2. **Компьютер c установленным Python 3.10+** (подойдёт Windows, macOS или Linux).
3. **Токен LLM** (например, OpenAI API key) — нужен для интеллектуальных ответов. Если ключа нет, бот всё равно будет работать, но ответит простыми шаблонными сообщениями.
4. **Токен бота** от @BotFather — получаете на шаге ниже.

## Шаг 1. Зарегистрировать бота в Telegram

1. Откройте чат с [@BotFather](https://t.me/BotFather).
2. Команда `/newbot` → придумайте имя (например, `Volna Assistant`).
3. Получите токен вида `123456:ABC-DEF...` — **сохраните его**, он нужен в `.env`.
4. (Опционально) Задайте описание, аватар и меню команд:
   - `/setdescription` → коротко опишите, что бот помогает узнать о ЖК «Волна» в Уфе.
   - `/setuserpic` → загрузите логотип.
   - `/setcommands` → можете добавить подсказки (`start`, `help`, `callme`).

## Шаг 2. Склонировать репозиторий

```bash
git clone <ваш-fork-или-zip> volna-bot
cd volna-bot
```

## Шаг 3. Установить зависимости

Установите зависимости в виртуальное окружение (рекомендуется):

```bash
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

## Шаг 4. Настроить переменные окружения

Создайте файл `.env` в корне рядом с `bot.py`:

```env
TELEGRAM_TOKEN=ваш_токен_от_BotFather
LLM_API_KEY=ваш_ключ_LLM_или_оставьте_пустым
LLM_MODEL=gpt-4o-mini     # Можно поменять на другой, поддерживаемый API
PROMPT_SYSTEM=Ты — вежливый помощник ЖК "Волна" в Уфе. Узнай потребности и оставь контакт.
```

> Если `LLM_API_KEY` пуст, бот будет отвечать предзаданными фразами. Вы сможете подключиться вручную через операторскую консоль.

## Шаг 5. Запустить бота

```bash
python bot.py
```

Бот начнёт опрашивать Telegram через long polling. Остановить — `Ctrl+C`.

### Что умеет бот

- Приветствует и задаёт наводящие вопросы (дата покупки, тип квартиры, телефон для связи).
- Отправляет ответы с помощью LLM, используя историю диалога пользователя из SQLite.
- Автоматически логирует все сообщения в `bot_data.db` (таблицы `users`, `messages`).

## Шаг 6. Работать вручную через операторскую консоль

1. Убедитесь, что бот запущен хотя бы раз (чтобы создалась база `bot_data.db`).
2. Запустите операторскую консоль в новом окне терминала:

```bash
python operator_console.py
```

Консоль предложит выбрать действие:

- **Просмотр диалогов** — выводит список последних пользователей, их id, время и крайнее сообщение.
- **Чтение диалога** — покажет всю переписку с выбранным пользователем (кто что писал).
- **Ответить пользователю** — отправит сообщение через Telegram от имени бота; ответ сохранится в базе.
- **Переключить автоответчик** — можно временно отключить LLM для конкретного пользователя, чтобы отвечать вручную.

## Структура проекта

```
README.md              — эта инструкция
requirements.txt       — зависимости (aiogram v3, openai, python-dotenv, sqlite-utils)
bot.py                 — основной бот (LLM + запись переписок)
operator_console.py    — CLI для операторов (просмотр и ответы)
bot_data.db            — база SQLite с переписками (создаётся автоматически)
```

## Кратко о логике бота

1. **Получение сообщений**: aiogram слушает апдейты и пишет сообщения в SQLite (`messages`).
2. **Контекст**: при обращении к LLM берётся история последних 10 сообщений конкретного пользователя.
3. **LLM-ответ**: вызывается OpenAI Chat Completions (или совместимый API с таким же форматом). Если ключа нет — используется fallback-ответ.
4. **Сценарий лидогенерации**: стартовое приветствие + сбор контактных данных (имя, телефон, интересуемый тип жилья, бюджет, желаемая дата).
5. **Ручное вмешательство**: оператор может открыть консоль и отправлять ответы в любой момент. Все ответы также пишутся в базу, чтобы LLM видел контекст.

## Настройка хостинга (коротко)

- **VPS**: установите Docker или PM2 + systemd; запустите `python bot.py` как сервис.
- **Webhook**: если хотите вебхуки, замените `polling()` на `start_webhook()` в `bot.py` и используйте `https://<домен>/bot<token>` с TLS.
- **Резервные копии**: периодически копируйте `bot_data.db` и `.env`.

## Частые проблемы

- «`Unauthorized`»: проверьте `TELEGRAM_TOKEN`.
- «`401 from OpenAI`»: неправильный `LLM_API_KEY` или модель.
- Бот молчит: убедитесь, что процесс запущен и интернет есть; в Windows проверьте фаервол.

## Безопасность

- Не публикуйте `.env` в репозиторий.
- Ограничьте доступ к операторской консоли (используйте отдельный пользователь OS или SSH).
- При хостинге на сервере обновляйте зависимости и ставьте автоперезапуск сервиса.

Успешной работы! Если нужен быстрый тест, запустите `python bot.py` и напишите боту в Telegram — он сразу начнёт собирать лиды по ЖК «Волна».
